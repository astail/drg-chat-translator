  - **セットアップをやり直したときに前の言語の設定が残る不具合**を見つけて直した。
    `zh-tw` でセットアップしたあと `ja` でやり直すと
    `DRGT_INCOMING_SKIP_LANGUAGES=zh` が残り、日本語の人の画面に中国語の発言の訳が
    出なくなっていた。`language_settings()` が常にこの項目を返すようにして、
    zh-tw→ja / ja→zh-tw / ru→ko のやり直しで上書きされることを確認した

- **APIキーを入力し直さないときの provider の書き込み**（`configure`）。選んだ
  サービスのAPIキーが既に OS の環境変数にあって「入力し直しますか？」に n と
  答えると、早期 return して `DRGT_PROVIDER` が書かれず、`settings.ini` の既定
  （`deepl`）で動いてしまう不具合があった（main にもあったもの）。書き込みを
  1か所にまとめて直し、3経路を確認した
  - 環境変数のキーを使い回す: `DRGT_PROVIDER` が書かれ、キー自体はファイルに
    書かない（OS の環境変数のほうが優先されるので二重に持たない）
  - APIキーを空欄で中止: `settings.ini` は作られない（回帰させていないこと）
  - 普通に入力: `DRGT_PROVIDER` とキーの両方が書かれる

- **配布物を `README.txt` 1つに絞った変更**（2026-09-19）
  - README とドキュメント10ファイルの相対リンク・アンカーがすべて実在する
    ことをスクリプトで確認（`README.md` は日本語の本体のまま。冒頭の言語
    リンクから各言語へ行く形を続ける）
  - `i18n.readme()` がファイル名ではなく GitHub の URL を返すようにし、
    6言語ぶんの完了画面の行と、URL が指す README が実在することを確認
  - zip に入れるのは `DRGTranslate.exe` / `settings.example.ini` /
    `README.txt` / `LICENSE` の4つだけにした。`release` の手動実行で
    実際にできた zip の中身がこの4つであることを確認
  - `--selftest --fake` と `tools/mock_test.lua` の client / host は引き続き PASS

## 未検証

- 翻訳元を日本語以外にした設定で、**実際にキーボードでチャットを打った**ときの動作。
  実機では `SIMSAY`（チャット欄から送ったときと同じ `Server_NewMessage` を通る）で確認しました
- **中継を同僚ドワーフが受け取るところ。** 実機で確認したのはソロ（自分がホスト）
  までで、複数人のロビーでは試していません。中継は自分の翻訳送信とまったく同じ
  `Server_NewMessage` を通り、そちらは実機で動いているので届くはずです
- `host_relay.sender = "original"`（元の発言者の名前で流す）。サーバ側で名前が
  上書きされる可能性があるため既定にしていません
- インストーラの実行。MOD の導入はファイルコピーで行ったため、`install.ps1` を
  実機のゲームフォルダに対して流してはいません
- オーバーレイ（`DRGT_OVERLAY_ENABLED=true`）の実機での見え方
- **多言語化したあとの実機での通し確認。** 変更したのは文言の差し替えと設定の
  書き込みで、翻訳経路そのものには触れていませんが、ゲームを起動しての確認は
  まだしていません
- **ロシア語・繁体字中国語で訳文がゲーム内に描画されるか。** ゲームの言語設定に
  その2つの項目があること（`Localization/Game/zh-TW` と `ru`）までは確認しましたが、
  実際に描画されるところは見ていません。日本語・韓国語・簡体字中国語は実機で確認済みです

hook 名・構造体の定義は
[DRG-Modding/FSD-Template](https://github.com/DRG-Modding/FSD-Template) のヘッダーダンプと
ゲーム本体バイナリの文字列から確認した実物ですが、実際の挙動は必ず一度確かめてください。
うまく動かないときは `config.lua` の `debug = true` にして UE4SS コンソールのログを見てください。
