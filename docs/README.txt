----------------------------------------------------------------
 日本語 (Japanese)
----------------------------------------------------------------

  1. 翻訳サービス（DeepL / Claude / OpenAI）の API キーを用意する
  2. DRGTranslate.exe を起動し、画面の案内どおりに進む
  3. 黒い窓を出したまま Deep Rock Galactic を起動する

  最初に言語を聞かれます。そのあとの案内は選んだ言語で出ます。

  初回の起動で「Windows によって PC が保護されました」と出ることがあります。
  署名の無いアプリのためです。「詳細情報」→「実行」で進めてください。
  配布ファイルが本物か確かめたいときは、リリースに添えた .sha256 と照らし合わせてください。
  詳しい説明: https://github.com/astail/drg-chat-translator/blob/main/README.md


----------------------------------------------------------------
 English
----------------------------------------------------------------

  1. Get an API key for a translation service (DeepL, Claude or OpenAI)
  2. Run DRGTranslate.exe and follow what it asks
  3. Leave the console window open and start Deep Rock Galactic

  Setup asks for your language first, so the rest is in your language.

  Windows may show "Windows protected your PC" on the first run, because the
  app is not code-signed. Click "More info", then "Run anyway".
  To check the download is genuine, compare it with the .sha256 on the release page.
  Details: https://github.com/astail/drg-chat-translator/blob/main/README.en.md

 简体中文 (Simplified Chinese)
----------------------------------------------------------------

  1. 准备一个翻译服务（DeepL / Claude / OpenAI）的 API 密钥
  2. 运行 DRGTranslate.exe，按提示操作
  3. 保持黑色窗口开着，然后启动 Deep Rock Galactic

  最先会问你的语言，之后的说明都用你选的语言显示。

  首次运行时可能会出现"Windows 已保护你的电脑"。这是因为应用没有数字签名。
  点击"更多信息"→"仍要运行"即可。
  如需确认下载的文件是否正版，请与发布页面附带的 .sha256 对照。
  详细说明: https://github.com/astail/drg-chat-translator/blob/main/README.zh.md

 繁體中文 (Traditional Chinese)
----------------------------------------------------------------

  1. 準備一個翻譯服務（DeepL / Claude / OpenAI）的 API 金鑰
  2. 執行 DRGTranslate.exe，依照提示操作
  3. 保持黑色視窗開著，然後啟動 Deep Rock Galactic

  最先會問你的語言，之後的說明都用你選的語言顯示。

  第一次執行時可能會出現「Windows 已保護您的電腦」。這是因為應用程式沒有數位簽章。
  請按「其他資訊」→「仍要執行」。
  若要確認下載的檔案是否為正版，請與發行頁面附上的 .sha256 對照。
  詳細說明: https://github.com/astail/drg-chat-translator/blob/main/README.zh-TW.md

 Русский (Russian)
----------------------------------------------------------------

  1. Получите API-ключ сервиса перевода (DeepL, Claude или OpenAI)
  2. Запустите DRGTranslate.exe и следуйте указаниям
  3. Оставьте окно открытым и запустите Deep Rock Galactic

  Сначала спросят ваш язык, дальше всё будет на нём.

  При первом запуске Windows может показать «Система Windows защитила ваш
  компьютер» — у программы нет цифровой подписи. Нажмите «Подробнее» →
  «Выполнить в любом случае».
  Чтобы убедиться, что файл подлинный, сверьте его с .sha256 на странице релиза.
  Подробности: https://github.com/astail/drg-chat-translator/blob/main/README.ru.md
