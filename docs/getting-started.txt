DRGTranslate - automatic chat translation for Deep Rock Galactic
================================================================

  Full documentation: README.en.md
  Other languages:    README.md (日本語) / README.ko.md / README.zh.md /
                      README.zh-TW.md / README.ru.md

- Three steps

  1. Double-click DRGTranslate.exe
  2. Follow what it asks
       - First, pick your language. Everything after that is shown
         in the language you picked
       - It looks for the game folder by itself
       - If UE4SS is missing, it offers to install it (answer Y)
       - It copies the mod into the game
       - Pick a translation service and paste your API key
  3. Leave the console window open and start Deep Rock Galactic

  From the second launch on, just start the exe (it asks nothing).

- What you need to bring

  An API key for one of these translation services:

    DeepL   https://www.deepl.com/pro-api              has a free tier
    Claude  https://platform.claude.com/settings/keys  good with slang (pay as you go)
    OpenAI  https://platform.openai.com/api-keys       good with slang (pay as you go)

  Claude and OpenAI need a credit card. These are separate from consumer
  plans such as ChatGPT Plus or Claude Pro.
  Rough prices are listed under "Before you start" in README.en.md.

  You do not need to install Python (it is bundled in the exe).

- What it does

  Incoming  Chat in other languages is shown translated into your language
  Outgoing  What you type is translated and sent in other languages
  Relay     While you host, translations of what others say go to everyone

  You choose the languages at the very start of setup (and can change them
  later in settings.ini).
  Press F9 in game to turn translation on and off.

- Changing settings

  settings.ini is created next to the exe. Double-click it to open it in
  Notepad (on a PC that hides file extensions it shows up as "settings").
  Every option is explained inside that file, in English.
  Restart DRGTranslate.exe after you save your changes.

  Commonly changed options:
    DRGT_UI_LANG=en                  language of setup and the console window
    DRGT_OUTGOING_TARGETS=ja,ko,zh   languages your messages are translated into
    DRGT_RELAY_ENABLED=false         do not relay even while hosting
    DRGT_OVERLAY_ENABLED=true        small window, when in-game display fails

  To run setup again from the start, delete settings.ini and launch
  DRGTranslate.exe (you will have to paste your API key again).

- Things to be aware of

  - Set the game language to the one you read, or text shows up as boxes
  - The exe is not signed, so antivirus software may warn about it
  - Chat text is sent to the translation service

More detail: README.en.md, or https://github.com/astail/drg-translation
